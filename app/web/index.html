  2. 点右上角 扫一扫，扫描左侧二维码
  3. 手机上点 确认登录，这里会自动开始扫描网盘

  1. 浏览器打开 pan.baidu.com 并登录你自己的账号。
  2. 按 F12 打开开发者工具 → 切到 Network（网络） 面板 → 刷新页面。
  3. 点开任意一条发往 pan.baidu.com 的请求，在 Request Headers 里找到 Cookie。
  4. 把 Cookie 整段值复制粘贴到下面（至少要包含 BDUSS=…，带上 STOKEN=… 更稳）。
